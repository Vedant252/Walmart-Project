# Walmart-Project

# 🛒 Walmart Sales Analysis | SQL + Python

## 📌 Project Overview

This project is an end-to-end **Sales Data Analysis** solution built using **Python** and **MySQL** to uncover actionable business insights from Walmart transaction data.

The workflow includes data cleaning, preprocessing, feature engineering, SQL analysis, and solving real-world business problems using advanced SQL concepts such as **CTEs, Window Functions, Aggregate Functions, CASE Statements, and Date Functions**.

The project demonstrates a complete analytics workflow followed by data analysts from raw data to business insights.

---

# 🎯 Objectives

* Clean and preprocess raw Walmart sales data using Python.
* Load cleaned data into MySQL.
* Solve business problems using SQL.
* Generate meaningful business insights from transactional data.
* Demonstrate SQL and data analysis skills through real-world use cases.

# 📊 Business Problems Solved

The project answers several real-world business questions:

1. Revenue generated by each product category.
2. Highest-rated category in every branch.
3. Busiest day of the week for each branch.
4. Average, minimum, and maximum customer ratings by city and category.
5. Most frequently used payment method in every branch.
6. Total profit generated by each category.
7. Number of transactions across Morning, Afternoon, and Evening shifts.
8. Branch-wise sales performance.
9. Customer purchasing patterns.
10. Revenue trends across categories and branches.
